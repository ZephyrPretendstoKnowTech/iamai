  `connect.scanned` allow.links to render it as a link.
- **`tenant.tip` contains "confirm"; `connect.scanned` forbids "confirm".** The

### Judgment calls (Part 1)

- **The `IAMAI limitations` panel and the opener budget.** §3 requires the panel
  open by default; its five items are ~16 sentences / ~240 words, and the
  `connect.signedOut` budget is 14 sentences / 220 words measured on page prose
  outside repeaters. The inventory counts an open `<details>`'s `<p>`/`<li>`
  children. Resolution: the panel is open (§3) but its intro and items render as
  `.limits-intro` / `.limit` `<div>`s, outside the inventory's prose blocks —
  the same way the permissions caveats sit outside the budget by being closed.
  The summary is captured; the copy is one file. (Measured, not assumed — the
  opener budget is green.)
- **"Raised" vs the raised-surface rule.** §3 calls the panel "raised", but §8.6
  and design-lint 6 keep `--bg-raised` for phases and export entries only. The
  panel separates by a hairline border, not `--bg-raised`.
- **The page tip.** No `PageTip` component exists app-wide (§8.8's collapse/
  localStorage is unbuilt across surfaces and not a Part 1 bullet). The opener's
  and scanned state's licence/records tips render as a plain `.tip` element
  (content source, contract selector, `tipMax` budget), without the collapse.
- **`baselineUpdated`.** `checkAuthorHead` returns only whether the head SHA
  differs and its date. The changed-policy count and the review rows come from a
  new `baselineChanges(head)` in `baseline.ts` using the GitHub compare API
  (`/compare/{pinned}...{head}`, `api.github.com`, already an allowed request
  host). The line shows only when the head differs AND the change list is
  non-empty, so the count and rows are always real; both calls fail closed, so
  the line never appears offline (and so is hidden in the inventory's mock
  states, keeping `connect.noScan` within budget).
