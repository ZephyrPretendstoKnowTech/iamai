## The vision, in one paragraph
IAMAI Planner is an expert that has already looked at the tenant. It gives the path: what to do, in doing order, with the exact change. It also gives the pitfalls: what the scan already knows will bite if the admin does it as written, named with its fix before they act. Nobody gets locked out is the design goal. Where it can't read, it says nothing. Useful, not defensible. The full text and the seven audit questions are in intent.md. Every audit uses them, and 2 (value) and 3 (pitfalls) are new.

## How we work
- **The loop, one section at a time:**
  1. Audit the section in Claude in Chrome on the owner's tenant (getiamai.com/planner; the owner is signed in). Read every line against the seven questions. Report a short, plain findings list.
  2. The owner picks.
  3. One branch from `origin/main`, small fixes, then: tsc, `node scripts/step-snapshots.mjs` (a subject with "[snapshots]" when they move), focused tests, `npm run verify -- --prepush <tests>`.
  4. Ask before pushing. A push to main deploys.
  5. Re-check in Chrome.
- **Never assume, always ask.** Do the literal ask. Ask before any fix, push, deploy, tenant scan or agent launch not approved in the same message. No agent fleets.
- **Don't widen scope.** A finding outside the round goes on a list for the owner.
- **Decide small calls yourself; batch the direction-changing questions.** Explain an unfamiliar concept with a real scenario before asking.
- **Tests:** run with `--test-isolation=none`, as `npm test` does. Put `src/content/content.test.ts` first, because some files alone hit an import cycle. CI runs on demand only.
- **Heredocs lose backslashes** (`\b`, `\n`, `\'`). Use the Edit tool for any line that has them.
- **Chime is in call mode:** call only when the owner is needed.

3. **3.8 Create the Policies in Report-only** (owner-approved placement, end of section 3).

   - **Confirm the plan re-dates** from the report-only start the scan sees.
   - **Present the step's anatomy and wording to the owner before building.** It's a new step, so the template applies.
