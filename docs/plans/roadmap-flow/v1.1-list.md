- **4.3's session and name correction lines never showed in review.** Session is a material field (changedFields.ts MATERIAL_ROOTS), so a session difference should raise the correction: find out why a 4-hour sign-in frequency did not. A renamed tagged policy is adopted under its new name, so the name module may be unreachable by design; decide whether it goes.
