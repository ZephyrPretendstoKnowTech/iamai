How this becomes enforceable in the repository

  1. Place this pack under docs/design/approved/reference/.
  2. Add the reference hashes to the repository design manifest.
  3. Rewrite the brand manifest dark block from Deep Mineral to Blue Slate and pin its exact roles.
  4. Update the design-authority manifest’s brand dark name to Blue Slate and logo direction to Threshold.
  5. Install iamai-threshold-master.svg as the source master under src/brand/logo/; all derivatives come from it.
  6. Update runtime tokens/tests that still pin Deep Mineral byte-for-byte.
  7. Move the rendered comparison target from pre-brand canonical HTML shots to these derived references while keeping canonical HTML as anatomy authority.
